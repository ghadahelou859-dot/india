دعوة سامر وسمر — نسخة GitHub Pages

طريقة الرفع:
1. افتحي المستودع في GitHub.
2. اختاري Add file ثم Upload files.
3. فكّي ضغط الملف ZIP أولاً.
4. ارفعي index.html وstyle.css وscript.js ومجلد images كاملًا.
5. لا ترفعي مجلد samer-samar-github نفسه؛ ارفعي الملفات الموجودة داخله.
6. من Settings > Pages اختاري Deploy from a branch.
7. اختاري main و /(root) ثم Save.

مهم:
- لا تغيّري أسماء الصور أو مجلد images.
- يجب أن يبقى index.html في الصفحة الرئيسية للمستودع.
